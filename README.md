# Ubuntu — Omarchy theme

Tema inspirado en la identidad visual de Ubuntu: base aubergine, acentos naranja y fondos de escritorio de la familia Ubuntu.

## Instalación

```bash
omarchy theme install https://github.com/ciprianotoor/omarchy-ubuntu-theme.git
omarchy theme set ubuntu
omarchy theme refresh
```

Para cambiar entre los fondos incluidos:

```bash
omarchy theme bg next
```

Este repositorio contiene únicamente el tema; no instala Omarchy, Arch Linux ni aplicaciones. Ubuntu y sus marcas pertenecen a Canonical Ltd.; este es un tema comunitario no oficial.
